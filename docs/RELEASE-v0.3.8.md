# Flomo Safe Sync v0.3.8

设置页底部新增“支持开发”，可查看微信赞赏码和支付宝收钱码。打赏完全自愿，不会解锁额外功能；已有设置、同步记录和全部同步功能保持不变。

收款码只在用户主动打开弹窗时从用户提供的阿里云 OSS 图床加载。若图床图片加载失败，可点击“打开原图”。

生产构建内嵌上游 MIT 版权与许可声明，运行安装包继续只包含三个插件文件且不包含 `data.json`。

BRAT 更新使用 Release 中的独立 `main.js`、`manifest.json` 和 `styles.css`。手动安装下载 `flomo-safe-sync-0.3.8.zip`，覆盖这三个文件后重载插件，保留原 `data.json`。

此版本作为预发布测试包提供。验证范围及限制见 `VALIDATION-v0.3.8.md`。
