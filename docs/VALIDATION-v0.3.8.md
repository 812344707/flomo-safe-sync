# Flomo Safe Sync v0.3.8 验证记录

验证日期：2026-09-07

## 变更范围

- 设置页底部增加紧凑的“支持开发 / 查看收款码”入口。
- 弹窗并排展示微信赞赏码和支付宝收钱码，窄窗口改为上下排列。
- 收款码使用用户提供的阿里云 OSS 图床，只在主动打开弹窗时加载；提供打开原图的后备入口。
- `manifest.json` 使用 Obsidian 官方 `fundingUrl` 字段登记两个自愿支持入口。
- 未增加会员功能，不改变配置结构、同步逻辑、既有设置或同步记录。

## 安装包边界

安装 ZIP 继续只包含 `flomo-safe-sync/main.js`、`flomo-safe-sync/manifest.json` 和
`flomo-safe-sync/styles.css`，不含 `data.json`。收款码图片不写入 Vault，也不进入插件设置文件。

安装覆盖前后对隔离测试库 `data.json` 计算 SHA-256，摘要保持一致。生产 `main.js` 内嵌完整
MIT 版权与许可声明；安装包通过 ZIP CRC 和精确文件清单检查。

## 外部依赖边界

收款码图片由用户提供的阿里云 OSS 图床托管。验证时可正常访问，但插件无法保证第三方图床
长期可用；图片加载失败时保留“打开原图”入口。打开打赏弹窗会向该图床发起图片请求。
