# Flomo Safe Sync v0.3.10

修改文件夹设置后，已有笔记及图片会自动迁移到对应目录，无需先删除再同步。

- 默认目录、标签对应目录、映射优先级和图片目录均支持迁移；现有文件名保持不变。
- 输入目录后按 Enter 或离开输入框保存，输入过程中不反复移动文件。
- 图片目录在旧默认目录内时一起移动；独立指定的图片目录保持独立。
- 保留手写正文、属性、同步历史和图床链接；更新笔记内的图片链接及指向被移动文件的链接。
- 同名目标追加后缀，文件不覆盖；迁移中断时保留进度，重载后继续，也可手动重试。
- 如果之前已改过设置，可在“同步范围”点击“按当前目录整理”。文件已删除时，仍需到“更新与安全”检查并重新导入。

目录整理无需登录或联网。YAML 注释被属性编辑器移除的文件，可在编号唯一、YAML 可解析时移动原文件；普通同步的受管区写入规则继续保留。

本版本先提供本地测试包。验证依据和边界见 `VALIDATION-v0.3.10.md`。
手动安装使用 `flomo-safe-sync-0.3.10.zip`，只覆盖 `main.js`、`manifest.json`、`styles.css` 后重载插件，保留原 `data.json`。
