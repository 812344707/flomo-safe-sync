## 复现实际界面检查

1. 准备上述独立测试库和独立 Obsidian profile，安装产品构建，保持令牌为空、自动同步关闭。
2. 使用 `--user-data-dir=/private/tmp/flomo-safe-sync-qa-v030/profile --remote-debugging-port=19223`
   启动测试进程。调试端口仅用于本地验收。
3. 运行 `node scripts/ui-smoke.mjs prepare` 打开设置窗口，再运行
   `node scripts/ui-smoke.mjs smoke`。
4. 原生文件流程另需把 `tests/native-test-plugin.ts` 构建为测试插件 `flomo-native-tests`，
   安装在同一独立库后运行 `node scripts/ui-smoke.mjs native`。

脚本校验 Vault 的绝对路径，路径不匹配会拒绝操作。

## 包与边界

`npm run package` 生成安装包。交付前检查 ZIP 结构、CRC、包内三文件与生产输出逐字一致，
并检查产物未包含虚构令牌、测试入口或测试笔记；校验值另见交付的 `SHA256SUMS.txt`。

- 已验证隔离 Obsidian 界面和本地文件操作；**未登录真实 Flomo 账号或验证实时 API 兼容性**。
- 全量分页校验检查响应结构、字段和重复数据，不保证上游返回内容真实完整。
- 不提供跨文件事务；归档和回收站有持久化操作意图及逐文件恢复，普通多文件更新失败时仍可能部分已写入。
- 标签保留使用“上次由 Flomo 写入的标签”判断手工标签来源；同名标签不能区分双重来源。
- 修改图片目录不迁移历史附件；远端链接过期后的下载效果需真实账号验证。
- 尚未在声明的最低版本 Obsidian 1.2.3 上实测。
