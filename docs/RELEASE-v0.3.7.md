# Flomo Safe Sync v0.3.7

修复本地文件删除、移动后重新导入时的错误分类和重复笔记检查。

## 本地缺失与内容冲突分别显示

- “本地文件缺失”独立计数，普通同步的受管区、身份及写入错误继续归入“冲突”。
- 同步提示说明普通同步不会自动重建文件，“连接与同步”提供缺失文件检查入口。
- 错误详情默认折叠，避免大量旧路径占满设置页。

## 重新导入前检测已有身份

- 在 Vault 其他路径发现相同 `flomo_slug` 的笔记时禁止重复导入。
- YAML 注释受管区标记丢失、重复字段或其他 YAML 错误不再使已存在的笔记身份漏检。
- 身份声明仅用于阻止重复创建。改写、归档及回收站仍要求完整受管区和身份校验。
- 恢复预览之后文件重新出现时，执行阶段再次检查并停止重复创建。

## 批量恢复界面

- 缺失列表分为“可重新导入”和“需检查”。已有同编号笔记列在“需检查”中，显示当前路径，不提供导入复选框。
- 增加“全选可导入”“取消全选”，执行按钮位于列表上方。
- 笔记列表内部滚动，避免批量恢复时需要滚过数百行才能执行。

操作路径：修正保存目录 → 更新与安全 → 检查缺失文件 → 全选可导入或手动勾选 → 按当前目录重新导入。

本版本不自动修补已存在笔记的保护标记，也不自动更改其同步路径。此类笔记需要单独核对，不能用重复导入代替修复。

## 安装与兼容

配置版本继续使用 6，升级保留原有设置、同步记录、文件名模板及附件映射。

BRAT 更新使用 Release 中的独立 `main.js`、`manifest.json` 和 `styles.css`。手动安装下载 `flomo-safe-sync-0.3.7.zip`，覆盖这三个文件后重载插件，保留原 `data.json`。

此版本作为预发布测试包提供。验证范围及限制见 `VALIDATION-v0.3.7.md`。
