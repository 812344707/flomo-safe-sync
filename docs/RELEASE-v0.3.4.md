# Flomo Safe Sync v0.3.4

## 树形标签级联选择

- 修复标签树只有层级缩进、没有父子级联选择的问题。
- 选中父级标签时，同时选中当前标签树中的全部子孙标签。
- 取消父级标签时，同时取消它的全部子孙标签。
- 只有部分子孙标签被选中时，父级复选框显示半选状态；再次点击父级会补全整个子树。
- 从已选标签列表移除父级时，也会移除它的全部子孙标签。

同步范围和“标签更新例外”共用相同逻辑。标签仍以完整名称保存和精确匹配，因此 `#工作` 与 `#工作/项目` 会作为两个明确选项参与同步判断。

## 兼容与安装

升级时保留现有设置、同步记录、文件路径和模板。此次更新不改写已有笔记。

BRAT 可直接读取本 Release 的独立 `main.js`、`manifest.json`、`styles.css`。手工安装可下载 `flomo-safe-sync-0.3.4.zip`，解压后将 `flomo-safe-sync` 文件夹放入 Vault 的 `.obsidian/plugins/`。

升级时保留原有 `data.json`。本安装包不含用户设置或真实账号数据。
