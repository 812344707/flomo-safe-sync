# Flomo Safe Sync v0.3.9

设置页新增第六个水平标签页“更多”。打开后直接显示醒目的“支持开发者”区域，以及微信赞赏码和支付宝收钱码原图。

本版取消 v0.3.8 的打赏弹窗。收款码不裁剪、不改图；宽窗口并排展示，窄窗口上下排列。已有设置、同步记录和全部同步功能保持不变。

收款码只有在打开“更多”标签页时才从用户提供的阿里云 OSS 图床加载。

BRAT 更新使用 Release 中的独立 `main.js`、`manifest.json` 和 `styles.css`。手动安装下载 `flomo-safe-sync-0.3.9.zip`，覆盖这三个文件后重载插件，保留原 `data.json`。

此版本作为预发布测试包提供。验证范围及限制见 `VALIDATION-v0.3.9.md`。
