# Flomo Safe Sync v0.3.0 测试版

本版本用于用户测试，暂标记为预发布版本。

## 主要更新

- 设置页改为五个标签页，文件名支持默认和自定义模式。
- 同步范围支持包括／排除，标签范围与保存目录映射分别管理。
- 图片保存目录可配置，YAML 模板提供大编辑区、变量插入和实时预览。
- 已有笔记支持正文与属性、仅正文、仅属性、仅首次导入四种更新方式。
- 远端删除支持保持原样、标记、归档和手选后移入 Obsidian 本地回收站。
- 增强受管区身份校验、API 响应与分页完整性检查，补充独立附件链接。

## 升级设置保护

升级包只包含 `main.js`、`manifest.json`、`styles.css`，不会包含或覆盖 Vault 内的
`data.json`。v0.3.0 会保留上次保存的设置，只为旧配置补充本版本新增的必要字段。
`false`、`0` 和空列表等有效选择不会被新版默认值替换。

建议先备份 Vault，在测试库或小范围内容上试用。安装时解压
`flomo-safe-sync-0.3.0.zip`，用其中的 `flomo-safe-sync` 文件夹替换插件运行文件，
保留原插件目录内的 `data.json`，随后重新加载 Obsidian。
