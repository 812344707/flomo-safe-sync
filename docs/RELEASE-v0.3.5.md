# Flomo Safe Sync v0.3.5

## 标签范围与保存目录

- 将原来分开的“同步范围”和“标签 → 保存目录”合并为一棵标签树。
- 每行左侧勾选是否包括或排除该标签，右侧直接设置专属保存目录；留空时使用统一的默认保存目录。
- 子级默认折叠，点击展开按钮逐级查看；搜索时自动显示匹配标签及其完整上级路径。
- 可切换为“仅看已选”或“仅看已排除”，顶部只显示标签数和专属目录数，不再重复堆叠标签卡片。
- 选择父级仍会级联全部子孙标签；只选择部分子级时，父级继续显示半选状态。
- 多标签命中时的目录映射优先级移入默认收起的高级设置，可集中调整顺序或恢复默认目录。

目录映射继续按完整标签精确匹配。本次没有加入目录继承，也不改变既有同步判断、现有笔记路径或历史附件目录。

## 兼容与安装

升级时原样保留同步范围、目录映射及其优先级、默认目录、模板、同步记录和文件路径，不需要配置迁移。

BRAT 可直接读取本 Release 的独立 `main.js`、`manifest.json`、`styles.css`。手工安装可下载 `flomo-safe-sync-0.3.5.zip`，解压后将 `flomo-safe-sync` 文件夹放入 Vault 的 `.obsidian/plugins/`。

升级时保留原有 `data.json`。本安装包不含用户设置或真实账号数据。
