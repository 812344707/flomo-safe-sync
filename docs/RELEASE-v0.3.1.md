# Flomo Safe Sync v0.3.1 测试版

本版本继续作为用户测试用预发布版本，重点优化设置界面、时间变量和图床兼容。

## 主要更新

- 自定义文件名新增 `year`、`month`、`day`、`hour`、`minute`、`second`，并默认展开时间变量参考。
- 同步范围标签使用树形层级列表；`工作/项目` 等完整标签按层级缩进显示，匹配规则仍为精确匹配。
- “标签 → 保存目录”根据同步范围自动生成标签行，只需选择右侧文件夹；页面同时提供未映射标签的默认位置。
- YAML 页面显示整篇新笔记模板，并区分插件受管区、标签合并区和用户可编辑区。
- 标签更新例外使用层级缩进结构展示。
- 记录 Flomo 原始图片地址与当前本地路径或图床地址。图床插件成功替换受管正文中的图片链接后，后续同步保留该链接，不再重新下载图片。
- 设置继续使用水平标签页；常规设置在足够宽的窗口中保持紧凑单行布局，窄窗口自动换行。

## 图片上传到图床后的处理

图片首次本地化后，插件记录 Flomo 原始地址和本地文件路径。图床插件把笔记中的本地嵌入替换为远程图片链接后，本插件会在下一次正文同步前读取受管正文，确认图片数量和顺序一致，再把记录更新为图床地址。之后即使本地图片已删除，也不会再次下载或把正文改回本地链接。

为了正确识别，图床插件应先把 Markdown 图片链接写回笔记，再删除本地文件。无法确认对应关系时，本插件不会猜测图床地址，而会按正常本地化规则处理。

## 升级设置保护

v0.3.0 的设置升级到新结构时，仅增加可选的图片映射记录。已保存的开关、数字、空列表、目录、模板、同步历史和未知扩展字段保持原值。安装包不含 `data.json`。

GitHub Release 同时提供安装 ZIP，以及 BRAT 直接更新所需的 `main.js`、`manifest.json`、`styles.css` 和校验清单。
