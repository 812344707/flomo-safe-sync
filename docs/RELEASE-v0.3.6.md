# Flomo Safe Sync v0.3.6

## 本地缺失笔记恢复

修复已经导入的 Markdown 文件被删除后，插件因为保留 `flomo_slug` 同步记录而静默显示“没有变化”的问题。

- 普通同步现在会检查已记录文件是否存在；即使 Flomo 更新时间没有变化，也会明确报告本地文件缺失。
- “更新与安全”新增“本地缺失笔记”，可先检查，再勾选需要恢复的笔记。
- 重新导入使用当前保存目录和目录映射，适合修正目录后重建误删笔记。
- 执行前重新读取完整 Flomo 快照，并核对 memo 仍存在、仍在同步范围内、没有命中“完全不导入”、没有归档或回收站状态。
- 只有一条记录的全部 Markdown 文件都已不存在时才允许重新导入；还会扫描 Vault 是否已有相同 `flomo_slug` 的受管笔记，任一旧文件重新出现便停止，避免重复笔记。
- 沿用原记录的附件目录和图片地址映射，已替换的图床链接不会因重新导入而丢失。

保存目录仍只影响新导入笔记。已有笔记需要改位置时，建议直接在 Obsidian 文件列表中移动，插件会跟踪重命名后的路径。

## 兼容与安装

升级时原样保留设置、同步记录、目录映射、模板、文件路径和附件映射，不需要配置迁移。

BRAT 可直接读取本 Release 的独立 `main.js`、`manifest.json`、`styles.css`。手工安装可下载 `flomo-safe-sync-0.3.6.zip`，解压后将 `flomo-safe-sync` 文件夹放入 Vault 的 `.obsidian/plugins/`。

升级时保留原有 `data.json`。本安装包不含用户设置或真实账号数据。
